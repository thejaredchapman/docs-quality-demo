# Set up daily reminders

This page shows you how to get a notification each day so you don't forget to check in.

1. Open **Settings**.
2. Tap **Daily reminders**.
3. Choose a time.
4. Tap **Save changes**.

At the time you picked, Tally sends a notification listing the habits you haven't checked off yet.

> **Note:** Please make sure you've allowed Tally to send notifications in your phone's settings. Reminders don't work without that permission.
