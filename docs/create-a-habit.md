# Create a habit

Use this page if you already have Tally set up and want to add another habit to track.

## Steps

1. Open Tally, select **New habit**, and type a name for the habit.
2. Choose how often you want to do it, and pick a color and an icon.
3. Select **Save changes**.

The new habit appears at the bottom of your **Today** list. If you don't like the name, you can simply rename it later.
